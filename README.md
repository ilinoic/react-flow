# React Flowwang 网页版 · AI 无限画布

在线直接开画：**<https://memeurd.online>**

一块无限大的画布，上面摆文本节点和图片节点，用连线说明「谁是谁的参考素材」；
每个节点自带一个 AI 对话框，就地输入提示词、就地生成，结果直接写回节点。
打开网页就能用，不用装任何软件。

---

## 亮点：AI Key 用你自己的

不卖额度、不抽成、不替你付模型钱 —— 你把自家 Key 填进来，画布照跑（BYOK，Bring Your Own Key）。

- **全部可配置**：供应商、Base URL、API Key、图片模型、图改图模型、文本模型、默认出图尺寸
- **开机自带三家预设**：模拟模式（不联网、出占位图）、OpenAI 兼容接口、通义千问 · 阿里云百炼；
  选中预设会自动填好地址和模型名，也可以再手动改
- **随手验货**：填完点「测试连接」当场验证，Key 失效 / 地址写错立刻现形
- **Key 留在你自己的浏览器里**：配置只写进本机 `localStorage`，不入库、不跟账号走；
  生成时由本站服务端接口把请求转发给上游，Key 不落库、不写日志
- **换环境要重填**：本地 `localhost` 和线上域名、不同浏览器之间各自隔离，第一次都需重填一次
- **没配也能玩**：默认「模拟模式」出占位图，先把画布拖熟再填 Key

> 出图尺寸、参考图张数、提示词长度都会影响你的钱包。想省钱就用便宜的文生图模型配小尺寸；
> 改图链路（带底图重画）通常比文生图贵，能一次说清需求就别反复「接着改」。

## 5 分钟上手

1. 打开 <https://memeurd.online>，在 `/signup` 用邮箱注册，收信点确认链接后回到 `/login` 登录
2. 进「AI 设置」（`/settings`）：选一个预设 → 填 API Key → 点「测试连接」→ 保存
3. 回画布（`/canvas`）：在空白处**右键** → 新建「文本节点」或「图片节点」
4. 在节点底部的输入框里写提示词，点「AI 生成」，结果写回这个节点
5. 想继续改，就直接写「把背景换成夜晚」，再点一次「AI 生成」

画布保存在云端账号下（`/projects` 是画布列表），同时有本地草稿自动保存兜底，不用担心手滑丢图。

## 画布怎么用

| 操作 | 说明 |
| --- | --- |
| 工具 | 选择工具（点选 / 框选）、抓手工具（拖动画布）、「待定」模式（什么都移不动，防误触） |
| 视角 | 滚轮缩放、拖拽平移、迷你地图定位、点阵背景、网格吸附可开关 |
| 建节点 | 空白处右键：新建文本节点 / 图片节点 / 参考图片节点 |
| 节点 | 文本节点双击编辑；图片节点点一下或拖文件进去上传；拖右下角改大小 |
| 连线 | 从节点四向连接点拖出连线；箭头指向的节点会「消费」这条参考 |
| 编辑 | 撤销 / 重做（100 步）、`Delete` 删除选中、右键菜单里复制节点、断开连线、填写提示词 |
| 对齐 | 选中 2 个以上节点会弹出对齐条：左 / 右 / 水平居中 / 顶 / 底 / 垂直居中 |
| 多画布 | 顶部标签页切换多个画布，各自独立 |
| 导出 | 右键空白处导出 JSON（`canvas-<名称>-<时间>.json`），图片一起打包在内 |

连线的语义很简单：**箭头指向谁，谁就拿到参考**。
文本节点贡献提示词，图片节点贡献参考图；多个来源会合并成这一次生成的上下文。

## AI 生成怎么玩

- **文生图**：节点还没图，写提示词直接生成一张新图
- **图生图 / 反复生成**：节点上已经有结果时，再点「AI 生成」默认在它上面接着改 ——
  图片当作底图做「按指令改图」，文字当作底稿做「在原文上改」。
  把节点底部的「基于当前图修改」开关关掉，就是丢掉底图从头重画
- **参考图**：普通节点底部有一格「＋ 参考图」，放一张图当参考，生成结果不会覆盖它
- **参考图片节点**：整块都是参考素材，点「AI 生成到新节点」时结果落到旁边的新图片节点
- **文本改写**：文本节点走文本模型，用来磨提示词、把长剧本压成一句可执行的指令
- **生成记录不落盘**：只保留最新这一张，草稿不会越用越大

两个模型各管一段：**图片模型**负责「从零画一张」，**图改图模型**负责「带底图改图」。
图改图那一格留空会按老规矩自动挑（比如文生图模型名里带 `t2i` 就自动换成 `wanx2.1-imageedit`），
主要留给自建网关 / 代理用。

## 供应商预设

选中预设会自动填好地址与模型名，可再手改：

| 预设 | Base URL | 图片模型 | 图改图模型 | 文本模型 |
| --- | --- | --- | --- | --- |
| 模拟模式 | — | — | — | — |
| OpenAI 兼容接口 | `https://api.openai.com/v1` | `gpt-image-1` | `gpt-image-1` | `gpt-4o-mini` |
| 通义千问 · 阿里云百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `wanx2.1-t2i-turbo` | `wanx2.1-imageedit` | `qwen-plus` |

只要 Base URL 说的是 OpenAI 兼容协议，任何中转站、自建网关、本地模型服务都能接。

## 常见问题

- **收不到确认邮件**：看看垃圾邮件；Supabase 免费邮箱额度有限，也可以等一会儿再试一次
- **生成报 401**：多半是 Key 失效或没填；去「AI 设置」重新填并点「测试连接」
- **生成报 502**：上游接口自己报错，面板里会显示上游原文，照着改模型名或提示词
- **图片显示不出来**：云端图片存在私有桶，节点里用的是 1 小时签名 URL，刷新页面或重新上传即可
- **测试连接过了，生成还是失败**：可能是当前模型不支持这类请求（比如用文生图模型去改图），
  换一个模型名再试
- **对齐条不出现**：需要选中 2 个以上节点（按住 Shift 点选，或框选）

## 本地运行与自部署

技术栈：Next.js 16（App Router）+ React 19 + `@xyflow/react`（React Flow 内核）+ Tailwind 4 +
zustand + Supabase（登录 / 云端画布）+ zod；可部署到 Vercel 或 Cloudflare Workers（OpenNext）。

本地启动、Supabase 建表、Vercel / Cloudflare 部署步骤与踩坑记录，以及目录结构、
端到端测试，都写在 [`ai-canvas-studio/README.md`](./ai-canvas-studio/README.md)。

```bash
cd ai-canvas-studio
pnpm install
# 复制 .env.example 为 .env.local，填 Supabase 两个变量
pnpm dev          # http://localhost:3000
pnpm test         # 单元测试
pnpm typecheck    # 类型检查
```
